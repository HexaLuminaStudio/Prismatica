## 一、我们是谁?

### 产品一句话

**Prismatica(棱溯客户端)** 是一款专为中文语言研究、教师教学、教材出版设计的**桌面级语料分析工具**,把行业级 NLP 能力塞进一个"双击打开就能用"的中文窗口,让您在 AntConc 和 Python 脚本之间,不必再做选择。

### 我们解决的问题

| 您现在的痛点 | Prismatica 的答案 |
|---|---|
| 想用 AntConc 做 KWIC、共现分析,但不能分析中文? | **9 大中文分析模块**:开箱即用,无需任何脚本 |
| 写 Python 跑 jieba + matplotlib 拼可视化,三小时还没出图? | **一键生成词云、共现网络、句法依存树** |
| 语料清洗规则每次都重写一遍? | **可视化清洗管线**:勾选勾选就行,实时预览前后差异 |
| 多个 HSK 等级 / 国别中介语语料杂乱堆在文件夹? | **多语料库管理**:一键切换、自动识别,分析结果自动指向当前语料 |
| 需要情感倾向、搭配强度、依存结构等多维指标,Excel 算不过来? | **学术算法内置**:Zipf / logDice / MI / t-score / G² / Dice 等统计量已封装 |
| 上网爬不到干净的语料? | **HSK + 全球中介语官方样本一键下载**(支持按等级 / 国别 / 体裁筛选) |

### 谁该用 Prismatica?

- **语言学研究者**(词汇学、句法学、社会语言学、二语习得)
- **汉语教师**(教学大纲设计、教材编纂、偏误分析)

## 二、六大核心功能模块

### 1. 语料导入与智能清洗 · 一切分析的基础

```
导入  →  清洗规则配置  →  清洗预览  →  写入语料库
```

- **多格式导入**:TXT / Excel / Word(docx) / 自定义结构化语料
- **可视化清洗管线**:
  - 繁简转换(OpenCC 引擎)
  - 全角/半角归一化、空白规范化
  - 编码统一(GBK → UTF-8 自动检测)
  - 段落去重、行级清洗、按正则批量替换
  - 中英文标点统一
- **清洗前后对比预览**,所见即所得
- **多语料库管理**:同时挂载 N 个语料库,顶部下拉切换,所有分析面板自动跟随
- **关键创新**:清洗结果**哈希缓存**,二次分析瞬间完成,不再重跑引擎

### 2. 词频分析 · 学术研究第一刀

- **多维度统计**:词次、频率、累积频率、Rank、Zipf 拟合
- **Zipf 曲线可视化**:自动绘制 R² 拟合,一眼判断语料是否符合自然语言分布
- **齐夫偏离度指数**:找出"反齐夫"的离群词(往往是专业术语)
- **停用词表**:内置百度/哈工大/中文停用词三种方案,可自定义合并
- **支持词性过滤**:只统计名词 / 动词 / 形容词等
- **导出**:CSV / Excel / JSON / 词频-累积频率图 PNG

### 3. 词语分析 · 共现与搭配的数学骨架

- **词汇丰富度**:TTR、STTR、MSTTR、MATTR(滑动窗口)
- **类符/形符比曲线**:可视化语料规模与词汇增长关系
- **词长分布、词频分布**:基础统计图
- **高频词表**:可一键导入搭配分析模块

### 4. 语境分析(KWIC)· 现代语料学精髓

- **关键词居中展示**:节点词彩色高亮,左右语境窗口可独立调节
- **四种索引行排序**:频次、字母、随机、关键词位置
- **二次检索**:叠加多层筛选条件(`/前文/词/后文/` 表达式)
- **详情弹窗**:点击任意索引行查看更大上下文
- **常见词检索**:中英文 / 数字混合,正则模式可选
- **导出**:CSV(可重新导入 Excel)/ TXT(论文引用格式)

### 5. 情感分析 · 态度与立场的量化

- **基于 HowNet / NTUSD 词典**:情感极性 + 强度评分
- **修饰语识别**:否定(不/没/未)、程度(很/非常/极)、转折(但/然而) 三类修饰回看算法
- **情感曲线**:段落级、句子级情感波动可视化
- **情感分布**:整体语料情感分布饼图
- **自定义词典**:可导入 CSV 词典扩展,支持权重设置
- **导出**:分析报告 PDF / CSV

### 6. 共现网络图 · 关系即视觉

- **节点=词语,边=共现强度**:与 Gephi 兼容的图论模型
- **三种共现算法**:窗口共现、句内共现、跨句共现
- **多种共现强度度量**:PMI、点互信息、卡方、Jaccard、互信息
- **布局算法**:力导向(Fruchterman-Reingold)、圆形、随机、Shell
- **节点重要度**:度中心性 / 中介中心性 / 接近中心性 / 特征向量中心性
- **交互**:
  - 鼠标拖动节点
  - 缩放、平移
  - 单击显示节点详情(频率、出度、入度、共现词列表)
  - 悬浮显示邻接关系
- **导出**:GEXF(可直接导入 Gephi)/ GraphML / PNG / SVG

### 7. 词语云图 · 让数据"长出来"

- **4 种布局**:矩形、椭圆、任意形状、用户自定义 mask
- **中文字体自动选择**:Noto Sans CJK / 思源宋体 / 系统已装字体
- **配色方案**:matplotlib 内置 30+ 种,支持自定义 colormap
- **词性过滤 + 频率阈值**:只画您关心的词
- **导出**:PNG / SVG / PDF(矢量级,可直接插论文)

### 8. 句法依存图 · 让句子结构一目了然

- **树状图**:ROOT 在顶,递归向下,标注依存关系
- **弧状图**:线性排列,弧线跨节点展示长距离依存
- **多引擎支持**:
  - 内置**规则式引擎**(jieba + 启发式,离线可用)
  - **HanLP 远程接口**(接入 hanlp.hankcs.com 商业级精度)
  - 可插拔**LTP / spaCy** 适配
- **CoNLL-U 标准导出**:结果可直接喂给 Stanford CoreNLP 等其他工具
- **多句批量分析**:自动按句号切分,逐句查看

### 9. 搭配分析 · 学术级搭配强度指标

- **5 大统计量**:**logDice**(语料库语言学主流)、**MI**(互信息)、**t-score**(学生 t 检验)、**G²**(对数似然比)、**Dice**(重叠系数)
- **z-score 标准化**:跨语料库比较时使用
- **滑动窗口**:2 词左右各 3/4/5 词候选
- **频次过滤**:最低共现阈值、最低节点词频阈值
- **导出**:CSV / Excel,可直接做差异搭配分析

## 三、独有特色 · 我们不一样

### 特色 1:从语料到结论,**全流程桌面化**

业界唯一:**把"清洗 → 分析 → 统计 → 可视化 → 报告"压在同 1 个窗口里**,无需切换工具。AntConc + Excel + Python + Gephi + R 四件套压缩为 Prismatica 一件。

### 特色 2:多语料库**即时切换**

不必为每个分析任务重新加载数据。一个 Prismatica 实例,**同时挂载 N 个语料库**,顶部下拉切换,所有分析面板自动跟随,适合做**跨语料库对比研究**(不同 HSK 等级 / 不同国别学习者 / 古今对比)。

### 特色 3:学术级指标,**开箱即用**

| 指标 | Prismatica | AntConc | Python 自研 |
|---|---|---|---|
| Zipf 拟合 R² | ✅ | ❌ | 需写 |
| logDice / G² | ✅ | ⚠️ 部分 | 需写 |
| MATTR 滑动窗口 | ✅ | ❌ | 需写 |
| CoNLL-U 依存导出 | ✅ | ❌ | 需写 |
| 句法依存可视化 | ✅ | ❌ | 需写 |
| 情感修饰回看 | ✅ | ❌ | 需写 |

### 特色 4:内置 HanLP + 离线引擎双模式

- **研究精度要求高**:接 HanLP RESTful,在线商业版精度(80+ 种 NLP 模型)
- **数据保密/无网环境**:切换为本地规则引擎,0 网络依赖
- **无缝切换**:**设置 → 后端选项**,不必重写代码

### 特色 5:跨工具格式兼容

- 导出的 **CSV** 可直接打开 Excel
- 导出的 **GEXF/GraphML** 可直接打开 Gephi
- 导出的 **CoNLL-U** 可直接打开 Stanford CoreNLP / spaCy
- 导出的 **JSON** 可直接对接 pandas / R / Stata

### 特色 6:**沉浸式**中文界面

不是套壳软件,**所有术语都做了本地化**:
- "Zipf slope" → "齐夫斜率"
- "concordance" → "语境分析"
- "association rule" → "关联规则"
- "logDice" → "对数搭配值"

每个术语首次出现都有小气泡解释,**论文引用不需要二次翻译**。

### 特色 7:**单机版**,数据不出本地

- **零云端依赖**:除了 HanLP 远程推理可选,其余分析全本地
- **适用于涉密场景**:不联网 = 不存在隐私问题
- **数据库本地存储**:语料缓存在您电脑 SQLite,不传给第三方

## 五、技术亮点

### 性能

- **后台多线程**:所有长任务(`>=1s` 计算)均在 `QThread` 中执行,UI 永不卡顿
- **SQLite 流式缓存**:清洗结果哈希化存储,二次分析毫秒级
- **Token 缓存(LRU)**:jieba 分词结果缓存 256 MB,避免重复计算

### 工程

- **PySide6 6.6+ LTS**:长期支持,Windows 10/11 稳定运行
- **qfluentwidgets Pro 版 UI**:Fluent Design 风格,符合 Win11 现代审美
- **可插拔架构**:每种分析都是"数据 → 引擎 → UI"三层,新增算法只需添加引擎
- **离线运行**:除 HanLP 远程推理外,所有计算本地完成
- **编译部署**:Nuitka 编译为单个 exe,目标用户无需安装 Python

### 安全

- **硬件绑定**:基于设备指纹的 HMAC 签名激活,**改系统时间无法绕过**
- **本地加密**:激活数据 AES-256-GCM 加密,密钥派生自设备指纹
- **零数据传输**:不上传任何语料到第三方服务器

## 七、为什么取名"棱溯"?

```
棱   ——  语言的切面 / 多角度折射(prism)
溯   ——  溯源 / 追溯 / 透溯本源
棱溯 = 折射语言的多重棱镜,追溯每个词、每个结构的本源
```

英文名 **Prismatica**(Prism 棱镜 + matica 语料后缀),表达"以棱镜视角分析语料"。

**品牌故事**:每个看似普通的词句,折射出认知、文化、情境的多重维度。我们想带给您的,是把语言"切面化"后看见的"原本看不见的东西"。
