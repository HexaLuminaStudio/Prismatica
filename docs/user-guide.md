## 1. 初识棱溯

**棱溯（Prismatica）** 是一款桌面端的中文学术语料分析软件。它把"获取语料"和"分析语料"两件原本需要分散在多个网站、多个工具里的事，集成在同一款应用里。

你可以用它做什么？

- **下载官方语料**：HSK 动态作文语料库、全球汉语中介语语料库，按条件检索后直接生成下载任务。
- **检索写作偏误**：自动识别错字、别字、漏字、错序、多余等偏误类型，并给出统计与可视化。
- **多维度分析语料**：词频、KWIC 语境、共现网络、句法依存、词云、情感倾向、词语搭配等十余种分析能力，对标 AntConc 的中文场景。
- **整理研究项目**：把同一课题下的语料、笔记、AI 解读聚合在一起，方便复盘与撰写报告。

**它适合谁？**

- 对外汉语教师与研究者
- 汉语国际教育、应用语言学硕博生
- 中文母语者中需要处理大规模文本的语言学爱好者

## 2. 安装与首次启动

### 2.1 系统要求

- **操作系统**：Windows 10 / Windows 11（64 位）
- **磁盘空间**：建议预留 5 GB 以上（语料与分析结果会持续增长）
- **网络**：下载语料与使用云端功能时需要联网

### 2.2 启动方式

- **已安装版本**：双击桌面"棱溯"图标。
- **便携版本**：解压后双击 `Prismatica.exe`。

### 2.3 首次启动的"四个一问"

> 我们承诺：棱溯不会偷偷上传你的语料内容。下列提示都为了让你了解本地数据的去向。

启动后，应用会依次询问：

1. **数据目录**：你的语料、笔记、报告、设置存在哪里？默认在安装目录下的 `datas/` 文件夹，**建议保持默认**，便于备份与迁移。
2. **模型设置**：是否启用 HanLP 句法分析？启用后可获得更精准的依存分析结果；不启用也能用基础功能。
3. **登录账号**：是否登录云端账号？登录后可使用云端订阅的语料与计费功能；不登录也能用所有本地功能。
4. **主导航模式**：使用"研究模式"（含项目管理、AI 聊天）还是"简洁模式"。

回答后即可进入主界面。

## 4. 账户与计费

### 4.1 为什么要登录？

- **云端订阅语料**：部分大规模语料需要云端权限才能下载。
- **AI 聊天额度**：AI 聊天按 token 计费，登录后从账户余额扣减。
- **跨设备同步**：你的研究项目配置（不含语料原文）可同步到云端。

### 4.2 登录 / 注册

进入"个人中心"→ 选择"登录"标签。棱溯支持：

- **邮箱 + 密码**
- **手机号 + 验证码**
- **兑换码激活**（用于将购买或活动赠送的兑换码绑定到当前设备）

### 4.3 余额与账单

- **余额**：展示当前可用 token 数与有效期。
- **账单**：每次扣费都会生成一条云端账单，可下载或申请退款。
- **设备管理**：查看当前账号绑定的所有设备；如需在另一台电脑登录，可在此解绑旧设备。

### 4.4 关于"强云端"原则

> 棱溯的所有鉴权与计费写操作都发生在云端。这意味着：
>
> - 你的余额永远是云端权威，**不会**因本地数据库损坏而丢失。
> - 卸载重装后，只要登录账号，余额立即恢复。
> - 本地仅缓存你的 token（用设备指纹派生的 AES-GCM 加密保存）。

## 5. 项目管理：把研究装进"文件夹"

> 项目 = 一次完整的研究单元。它把你选的语料、你的笔记、AI 解读放在一起。

### 5.1 创建项目

进入"项目管理"→ 点击"新建项目"→ 填写项目名称（必填）、研究主题（可选）、备注（可选）→ 完成。

### 5.2 项目仪表盘

打开一个项目后，会进入三栏仪表盘：

- **左栏 · 资源池**：当前项目关联的语料（从下载或导入处加入）
- **中栏 · 详情**：项目元信息、最近活动时间、统计概览
- **右栏 · 笔记 + AI 解读**：自由笔记 + 一键生成 AI 研究报告

### 5.3 AI 报告生成

在右栏点击"生成 AI 解读"→ 棱溯会基于当前项目的语料 + 笔记 + 你设定的研究问题，生成结构化报告。

> 报告生成过程中，仪表盘进入"忙碌"状态，导航切换会被锁定——这是为了防止你看到一半切换走导致上下文丢失。

### 5.4 把语料加入项目

在 HSK / 全球中介语下载结果页、HSK 作文检索结果页、偏误统计结果页、词频分析结果页，**任何结果表右上角的"加入项目"按钮**都会把当前结果添加到指定项目。

## 6. HSK 动态作文语料库下载

<!--img:hsk-download-->

HSK 动态作文语料库收录了母语非汉语的学习者参加 HSK 高等考试所写的作文，是研究中介语与偏误的权威资源。

### 6.1 检索方式（4 种）

棱溯把 HSK 官方提供的检索方式一一对应到界面：

| 模式 | 何时使用 |
|------|----------|
| **关键词检索** | 想知道学习者怎么写某个词或短语 |
| **上下文条件** | 想锁定"前 X 词 + 关键词 + 后 Y 词"的特定搭配 |
| **句法搭配** | 想检索某种句法关系下的关键词 |
| **错句类型** | 想直接看某种偏误类型（如"把"字句误用）的例句 |

### 6.2 操作流程

1. 进入 **HSK 下载** → 选择检索模式。
2. 在检索面板中填写条件 → 棱溯会**实时查询预计命中数量**。
3. 点击"创建任务"→ 应用自动跳到 **任务管理** 页并持续跟踪下载进度。
4. 下载完成后，语料可在 **HSK 作文检索** 中直接打开。

### 6.3 关于"批处理"

如果你是教师或科研人员，常常一次提交多组条件——**批处理面板**允许你把多个检索条件写进一个表格，一次性提交，全部完成后统一提醒。

<!--img:hsk-corpus-search-->

## 9. 偏误统计

<!--img:bias-->

> 偏误统计是棱溯的"明星功能"之一。它把 HSK 语料中用 `[C]`、`[B]`、`[L]`、`[D]`、`[R]`、`[Q]` 等标注的偏误自动归类，给出可视化与可下载的统计表。

### 9.1 偏误类型一览

| 标记 | 含义 | 示例 |
|------|------|------|
| `[C]` | 错字 | "已经"写作"以经" |
| `[B]` | 别字 | "在"写作"再" |
| `[L]` | 漏字 | "我北京"漏掉"在" |
| `[D]` | 多余字 | "我**的**中国朋友" |
| `[R]` | 错序 | "我把**很**喜欢"应为"我**很**喜欢" |
| `[Q]` | 缺词 | "我\_\_北京人"缺"是" |

### 9.2 操作流程

1. 进入 **偏误统计** → 选择语料（已下载的 HSK，或导入自己的 Excel/CSV/Word 文本）。
2. 勾选要统计的偏误类型（可全选）。
3. 点击"开始统计" → 几秒到几十秒后生成结果。
4. 结果区提供：
   - **统计表**：每类偏误的计数与占比
   - **可视化图表**：柱状图、饼图、关系图
   - **关联规则挖掘**（进阶）：自动发现"哪些偏误经常一起出现"

### 9.3 自定义偏误类型

如果你的语料用了非标偏误标记，可进入"偏误规则"面板新增正则表达式，棱溯会自动把它纳入统计。

### 9.4 导出

- **报告 PDF**：含图表 + 样例句
- **Excel 原始表**：含每条偏误的上下文
- **加入项目**：自动保存当前语料 + 规则 + 结果

## 10. 语料分析（对标 AntConc 的中文场景）

<!--img:freq-->

> 这是棱溯功能最丰富的一页。**顶部是切换面板**，10 余种分析能力按类别分组。

### 10.1 语料导入与切换

进入"语料分析"页前，你需要先选一份语料。

- **导入语料**：支持 Excel / CSV / Word 文本 / 纯文本。导入时可选择文本列、做基本清洗（去标点、去停用词、繁体转简体等）。
- **切换语料**：右上角的"语料切换器"会列出所有已导入的语料，一键切换。
- **多语料并行**：可同时加载多份语料做对比分析（如"教材语料 vs 学习者语料"）。

### 10.2 主要分析面板

| 面板 | 何时使用 | 关键能力 |
|------|----------|----------|
| **词频分析** | 想知道语料里哪些词最常见 | 词频表 / Zipf 曲线 / N-gram / 停用词管理 |
| **词语分析** | 想做词汇丰富度研究 | 类符/形符比 / 词汇分布 / 词汇增长曲线 / 高频词 |
| **语境分析（KWIC）** | 想看关键词的左右上下文 | 跨语料 KWIC 检索 / Concordance Plot 分布图 |
| **搭配分析** | 研究词与词的搭配强度 | MI / MI3 / T / LogDice / Z / Delta-P 六种统计量 |
| **共现网络** | 想一眼看出"哪些词常一起出现" | 词语共现网络图（networkx） |
| **句法依存** | 研究句子结构 | 依存句法树 / 主谓宾关系提取 |
| **词云** | 给报告做一张漂亮的封面图 | 词云图（matplotlib） |
| **情感分析** | 想知道语料整体情感倾向 | 情感得分 / 情绪分布 |

### 10.3 分析通用操作

- **保存到项目**：每个面板右上角都有"加入项目"按钮。
- **导出**：表格可导出为 Excel/CSV，图表可导出为 PNG/PDF。
- **AI 解读**（部分面板可用）：一键让 AI 总结当前结果。

### 10.4 关于"清洗"

> 中文语料里有大量"杂讯"——标点、数字、英文、表情符号、繁体字。**如果不洗，分析结果会被它们严重干扰。**
>
> 棱溯的"清洗面板"提供可视化预览：左边原文，右边清洗后，**所见即所得**。支持自定义规则。

### 10.5 性能建议

- 10 万字以内：几乎实时。
- 10 万–100 万字：建议关闭句法依存（共现网络仍可秒出）。
- 100 万字以上：建议使用"语料抽样"或分批分析。

## 11. AI 聊天（研究助手）

<!--img:chat-->

> 棱溯的 AI 聊天不是又一个 ChatGPT 客户端。它**默认能引用你当前语料**。

### 11.1 发起对话

进入 **AI 聊天** → 在底部输入框提问。可选附件：把当前语料片段附给 AI。

### 11.2 引用语料

在任意分析面板的"加入对话"按钮处点击，可把当前结果（如一段 KWIC 命中、一张统计表）发给 AI。

### 11.3 状态条

底部状态条实时显示：

- 当前会话累计消耗 token
- 估计剩余额度
- 流式输出进度

### 11.4 常见用法

- "请基于这份语料，总结学习者最常犯的 5 类偏误"
- "把这份 KWIC 结果整理成论文里能用的一段话"
- "对比教材 A 和学习者 B 在『把』字句使用上的差异"

## 12. 任务管理

- 清空已完成

## 14. 常见问题

**Q1：下载到一半关闭了应用，语料会不会坏？**
A：不会。棱溯使用 SQLite + 事务机制，下次启动会自动校验并续传未完成的部分。

**Q2：我的语料会被上传到云端吗？**
A：**不会**。语料原文始终留在你本地的 `datas/corpora/` 目录，云端仅同步元数据（项目名、检索条件、笔记等）。

**Q3：分析结果不准确怎么办？**
A：先检查「清洗」设置——大量结果异常往往是杂讯没洗干净。也可以在偏误统计页调整正则规则。

**Q4：AI 聊天为什么提示"余额不足"？**
A：进入"个人中心"→"余额"→ 充值或兑换码激活。AI 聊天按 token 计费，所有账单可在"账单"页下载。

**Q5：能离线使用吗？**
A：可以。**所有本地功能**（偏误统计、词频分析、KWIC、共现网络、词云、句法依存等）都完全离线。仅以下功能需要联网：
- 下载官方语料
- 登录 / 计费
- AI 聊天
- 项目配置同步

**Q6：怎么把研究结果整理成论文？**
