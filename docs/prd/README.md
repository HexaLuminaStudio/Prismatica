## 🎯 PRD-001 AI 分析解读（核心亮点）

**一句话**：每个分析结果旁边都有一个"AI 研究助理"按钮，一键生成带溯源、带数值、可直接写进论文的解读段落。

**关键能力**：
- ✅ 5 大分析模块（词频/搭配/共现网络/关键词/N-gram）AI 解读
- ✅ "三可原则"：可溯源（引到语料）、可证伪（附数值）、可拒绝（数据不足时主动说）
- ✅ 流式输出 + 引用跳转（点击 [节点:反问句] 直接跳到网络图）
- ✅ 本地优先（Qwen2.5-7B）+ 云端可选（DeepSeek-V3）
- ✅ 解读可收藏到项目（与 PRD-002 联动）

**关键交付**：每个分析页右侧抽屉 + 解读按钮 + 引用层

---

## 🗂️ PRD-002 研究项目（核心亮点）

**一句话**：把语料、分析配置、结果图表、笔记、AI 解读打包成一个可保存、可切换、可导出为论文素材的研究单元。

**关键能力**：
- ✅ 项目作为一等公民（顶栏切换 + 仪表盘）
- ✅ 资源池（所有分析结果自动归档，可标 ⭐ 候选）
- ✅ 内置 Markdown 笔记（支持资源引用 [[resource:xxx]]）
- ✅ 一键导出 Word/Markdown 素材包
- ✅ .prisma 项目文件（可分享/复现）
- ✅ 内置 3 套模板（中介语偏误 / 构式语法 / 语体对比）

**关键交付**：项目仪表盘 + 资源池 + 笔记 + 导出
